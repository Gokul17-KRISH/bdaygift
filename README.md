# Birthday Surprise Website 🎂✨

A special interactive birthday surprise web application created for Yuva.

## Features
- Interactive candle blowing animation 🕯️
- Custom music playback 🎵
- Animated photo frames & handwritten notes 💌
- Special personalized birthday message & quote 🤍
